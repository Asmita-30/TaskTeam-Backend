# 🔧 Team Task Manager - Backend API

RESTful API for Team Task Management system with role-based access control (Admin/Member), JWT authentication, and MySQL database.

## 🛠️ Tech Stack

- **Node.js** (v18+)
- **Express.js** - Web framework
- **MySQL** - Database
- **JWT** - Authentication
- **bcryptjs** - Password hashing
- **cors** - Cross-origin resource sharing
- **dotenv** - Environment variables
